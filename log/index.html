Patch Notes
Every game update since the launch of the public beta in January 2021
1.0.32026/08/31
  • Frame Data: Fixed notation for Malicious Meat
1.0.22026/08/30
  • Steam: Fixed bug where new boss characters were unlocked automatically
  • Steam: Fixed bug where Enter/Exit fullscreen didn't work
  • Story: You can now skip stories while in cutscenes
  • Frame Data: Added Synthetic Spice and Malicious Meat (when unlocked)
  • Coalescent Carb: misc balance adjustments
  • Synthetic Spice: misc balance adjustments and removed custom meter color
  • Mystery Meat: Fixed prejump to be throw invulnerable
  • Fixed bug where some remote sprites weren't loaded before the match
1.0.12026/08/26
  • Steam version now has ALL skins unlocked
  • Free version now defaults to locking premium skins in offline game modes
1.0.02026/08/26
  • Launch version! We're officially leaving Beta / Early Access
  • Updated splash art and logos
0.118.32026/08/22
  • Story: Fixed bug where Easy/Hard had CPU taking over both players
  • Reverted Summer Theme to July only
0.118.22026/08/21
  • Renamed "Arcade Mode" to "Story Mode" to better match the game experience
  • Added "Autoplay" option for Story Mode for those who just want to see the cutscenes
  • Adjusted CPU behavior to improve ability to land juggle combos
  • Extended the Summer Theme in August
0.118.12026/08/08
  • Modding: Arcade stories will now show up in the mod editor
0.118.02026/08/08
  • Added Arcade Mode!!
  • > Removed "Versus Boss" menu
  • > Re-locked bosses for all players
  • > Added three new boss characters
  • Gameplay: CPUs will now attempt to perform their combo trials
  • Gameplay: CPUs will now burst more randomly
0.117.22026/04/27
  • Lobbies: Named lobbies now have "Prevent Start" on by default
  • Fixed visual mistake with Noodle's Glitter portrait
  • Fixed a bug with music playing in the mod editor
0.117.12026/01/26
  • Added Ctrl+S, Ctrl+B shortcuts to the mod editor
  • Fixed a bug where mods wouldn't compile if the last line was a comment
  • Fixed error line numbers being slightly off
  • Fixed a bug where WIP content was accidentally playable
0.117.02026/01/04
  • Modding Editor has been completely redesigned!
  • New engine features:
  • > Projectiles can now be randomized like cancels
  • > RemoteAnimationConfig.offsetFromStoredPosition
  • > FrameConfig.armorMultiplier
  • > FighterStatsConfig.meterPartialColor
  • > FighterStatsConfig.meterFullColor
  • > FighterStatsConfig.meterGainedColor
  • Rewrote sprite loading
0.116.22025/10/11
  • Lobbies: VIP users can now make lobbies with custom IDs
0.116.12025/10/11
  • Mobile: Fixed bug where holding touch controls sometimes tried to select an image rendered below the canvas
  • Maintenance: Prep work for story mode launch
  • Maintenance: Fixed some dev tools (thanks clove)
  • Maintenance: Fixed bug with April Fools code when interacting with Cabinet Mode
  • Maintenance: Added admin tools for experimental lobby features
  • Maintenance: Added admin tools for screen recording
0.116.02025/07/27
  • Gameplay: Added throw tech lockout. Pressing any non-Throw button while getting thrown will prevent you from teching on a later frame
  • Gameplay: Fixed bug where meter gain during a Rapid combo was not working on non-combat meter gain (eg walking forward)
  • Gameplay: Changed meter gain during a Rapid combo to halve and then round down instead of rounding up
  • Noodle/Rice: Increased 2nd hit of 5L cancel window 6 > 11 frames
  • Rice: Increased Jump Drill hitstun frame advantage by 2, making it +1 on hit at point blank range
  • Beef: Lemon goes away if Beef is hit
  • Training: Added frame number and throw tech status to the hurtbox display
  • Modding: Fixed bug where picking two different mods with the same skin would cause P2 to switch to P1's character
0.115.22025/07/01
  • Modding: Removed matchmaker overlay from bottom left
  • Modding: Added docs for the following new mod features:

  • > ParryConfig.onAirborne

0.115.12025/04/17

  • Maintenance: Cleaned up April Fools character code
0.115.02025/04/12
  • April Fools gameplay changes have been reverted

  • AF Noodle: Fixed bugs related to projectiles/parry, fixed visual bugs, added and updated combo trials
  • AF Rice: Changed 5HL, increased range on 4L, misc QOL fixes
  • AF Beef: Reduced startup on a number of moves opening up new combo routes, fixed bug with ground bounce
  • Maintenance: Prep work for the April Fools archive

  • AF Pork: Increased meter gain on hit, removed armor from 4L but it now breaks armor and parries
  • AF Rice: Miscellaneous nerfs and behavior fixes
